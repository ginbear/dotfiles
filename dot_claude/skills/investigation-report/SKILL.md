# 調査結果の記録

調査結果を GitHub Issue に貼れる Markdown にまとめる。実際に Issue へ書き込むかはユーザーが判断するので、書き込みは指示があるまで行わない。

## 書き方

- **事実と推測を分けて書く**。事実は根拠(コマンドと出力、ログ、ドキュメントのリンク)を添える。推測には確信度と「何が観測されれば反証されるか」を添える
- 10行以上のコマンド出力やログは `<details>` で折りたたむ。出力は要約・整形せずそのまま貼る
- 実行したコマンドは、読み手が再実行できる形で出力の直前に書く

## 構成

~~~markdown
## 概要
<何が起きていて、何が分かったかを 2〜3 行>

## 事実
- <観測したこと>

  `<実行したコマンド>`

  <details><summary>出力</summary>

  ```
  <出力をそのまま>
  ```

  </details>

## 推測
- <推測>(確信度: 高/中/低。反証条件: <何が観測されれば否定されるか>)

## 未確認・次のアクション
- <まだ確認していないこと、確認方法>
~~~
